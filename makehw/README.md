# Make

Данная директория содержит пример автоматизации процессов разработки Python-проекта с использованием Make.

## Основная идея

Make используется не как набор команд, а как система управления зависимостями между действиями. Это позволяет объединить отдельные шаги (установка, проверка, форматирование) в единый воспроизводимый процесс.

## Реализованные возможности

- установка зависимостей
- статическая проверка типов
- проверка зависимостей проекта
- проверка и форматирование кода
- объединение всех проверок в единый pipeline

## Структура

- `practice/` — основная реализация задания

## Результат

Одной командой выполняется полный набор проверок проекта, что обеспечивает воспроизводимость и контроль качества кода.
