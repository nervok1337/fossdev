# Автоматизация проверки Python-проекта с помощью Make

## Описание

В рамках задания реализована система автоматизации основных этапов разработки Python-проекта. Все действия оформлены в виде target'ов Makefile.

## Реализованные задачи

### 1. Проверка зависимостей

Анализируются импорты в исходном коде и сравниваются с `requirements.txt`.

Команда:
```bash
make check-requirements
```

Результат:

* вывод отсутствующих зависимостей
* вывод неиспользуемых зависимостей

### 2. Проверка типов

Используется статический анализатор типов.

Команда:

```bash
make typecheck
```

Инструмент:

* mypy

### 3. Проверка стилей

Разделены два режима:

Проверка:

```bash
make lint
```

Форматирование:

```bash
make format
```

Инструмент:

* black

### 4. Цепочка проверок

Все проверки объединены в один target:

```bash
make check
```

Последовательно выполняются:

* проверка типов
* проверка зависимостей
* проверка стиля

## Установка и запуск

```bash
make install
make check
```

## До автоматизации

До использования Make все действия выполнялись вручную:

1. создание виртуального окружения
2. установка зависимостей через pip
3. запуск mypy
4. проверка форматирования кода
5. ручная проверка соответствия импортов и зависимостей

---

## Вывод

Make позволяет описывать процесс разработки как набор связанных действий. Это делает проверку проекта воспроизводимой и упрощает контроль качества.
